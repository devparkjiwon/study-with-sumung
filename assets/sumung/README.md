# 🐾 상명대학교 수뭉이(Sumung) 에셋 안내 및 교체 방법

본 폴더(`assets/sumung`)는 **스터디윗뭉(Study with Mung)**의 마스코트 캐릭터 이미지 에셋을 보관하는 폴더입니다.

기본적으로 정교하게 제작된 벡터 SVG 플레이스홀더 캐릭터가 탑재되어 있으며, 상명대학교 공식 수뭉이 이미지 또는 개인이 소장한 일러스트(PNG/SVG/WebP)로 언제든지 교체하여 사용할 수 있습니다.

---

## 🎨 에셋 파일 목록 및 규격

| 파일명 | 상태 | 설명 | 권장 크기 |
| :--- | :--- | :--- | :--- |
| `sumung_idle.svg` / `.png` | **대기 / 평상시** | 부드럽게 깜빡이며 사용자를 바라보는 기본 모습 | 512x512 px 이상 |
| `sumung_focus.svg` / `.png` | **집중 중** | 공부를 열심히 지켜보고 응원하는 모습 | 512x512 px 이상 |
| `sumung_shocked.svg` / `.png` | **마우스 감지** | 마우스 움직임을 포착하고 깜짝 놀란 표정 | 512x512 px 이상 |
| `sumung_celebrate.svg` / `.png` | **목표 달성/축하** | 25분/50분/1시간 또는 일일 목표 달성 시 환호하는 모습 | 512x512 px 이상 |
| `sumung_waiting.svg` / `.png` | **재시작 대기** | 다음 집중 시작을 5초 동안 카운트다운하며 기다리는 모습 | 512x512 px 이상 |

---

## 🔄 이미지 교체 방법

1. 앱 설정 화면(우측 상단 ⚙️)에서 **「📁 수뭉이 에셋 폴더 열기」** 버튼을 클릭합니다.
2. 위 표에 지정된 파일 이름(`sumung_idle.png`, `sumung_focus.png` 등)으로 원하는 이미지 파일을 복사하여 넣습니다.
3. 앱을 새로고침하거나 재실행하면 새로 추가한 이미지가 즉시 적용됩니다!
